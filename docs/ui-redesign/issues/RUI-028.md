## Integration points

- New: src/app/preferences.ts, src/ui/components/PreferencesPanel.ts

## Implementation tasks

- [ ] Parse and persist the bounded versioned schema from DATA_CONTRACTS.
- [ ] Offer help visibility, manual scale/precision, preferred view and reduced UI motion.
- [ ] Label optional display name as local to this device; store no scripts, replay contents or identifiers by default.
- [ ] Catch storage-denied/quota/corrupt-data cases and expose Reset Preferences.

## Acceptance criteria

- [ ] Refresh restores only validated preferences and never a live match or Worker.
- [ ] Changing presentation preferences cannot alter a loaded replay or physics config.
- [ ] The menu contains no fabricated signed-in team or cloud-sync status.

## Test evidence required

- [ ] New tests/preferences.test.ts: corruption, unknown version, bounds and storage failure.
- [ ] Browser: gear open/close, persistence and reset without simulation reset.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.

## Boundaries and completion

Preserve authoritative simulation, match, replay and Worker contracts. Views do not manipulate physics directly. New manual interactions must use the approved input/command path. Do not add unsupported battery, weather, lift, account or official-arena claims to match the illustration.
