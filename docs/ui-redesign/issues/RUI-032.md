## Implementation tasks

- [ ] Implement SC-01–22 critical paths, using probes only for observation/fixture setup.
- [ ] Validate actual downloaded JSON bytes, reload that file and perform full playback verification.

- [ ] At least one real browser Worker is used for sync/stale/source-lifecycle cases.
- [ ] No test title claims a download or pointer interaction without performing it.

- [ ] Run npm run test:browser in CI on exact candidate; retain existing smoke cases.
- [ ] Save traces/screenshots/logs and the exported fixture when a path fails.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.
