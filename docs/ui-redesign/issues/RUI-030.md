## Summary

The original global keyboard model and image labels cannot simply be copied into an accessible application.

## Source grounding

Planning baseline: `f5092ffa5aa8eeb9aaab016dfa4b8a303c14c12a`. [S22](https://www.w3.org/TR/WCAG22/) [S07](https://github.com/ther12k/robocon/blob/f5092ffa5aa8eeb9aaab016dfa4b8a303c14c12a/src/sim/input/InputManager.ts)

This issue describes proposed work. Re-check the implementation checkout before treating a gap as current; do not reintroduce or duplicate already-landed audit fixes.

## Integration points

- New: tests/uiAccessibility.test.ts and browser a11y scenarios
- All light UI components

## Implementation tasks

- [ ] Audit natural Tab order, visible focus, names/roles/values and dialog restoration.
- [ ] Check text/control contrast in every state and at 200% zoom/text growth.
- [ ] Provide readable arena/telemetry summaries and polite transition announcements.
- [ ] Document tested assistive technology and known canvas limitations; avoid unsupported conformance claims.

## Acceptance criteria

- [ ] No keyboard trap or global robot-cycle interception prevents normal document navigation.
- [ ] Enter/Space on focused UI controls does not also trigger simulator shortcuts.
- [ ] Controls remain usable with text expansion and without team colors.

## Test evidence required

- [ ] Automated semantic/accessibility scan plus manual keyboard checklist.
- [ ] Manual screen-reader journey: select robot, inspect status, load replay, interpret failure.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.

## Boundaries and completion

Preserve authoritative simulation, match, replay and Worker contracts. Views do not manipulate physics directly. New manual interactions must use the approved input/command path. Do not add unsupported battery, weather, lift, account or official-arena claims to match the illustration.

A completed PR names this planning ID and its real GitHub issue number, records any intentional deviation, and links its evidence. Numeric IDs are assigned only when issues are actually registered.
