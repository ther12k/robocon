## Integration points

- New: src/ui/components/ThrottleControl.ts
- Existing integration: manual command normalization

## Implementation tasks

- [ ] Implement 0–100% slider in 5% steps, default 50%, with visible numeric value.
- [ ] Apply Normal=1 and Precision=0.25 multiplier once to manual axes.
- [ ] Keep profile/spec limits, solver timestep and replay effective commands untouched.
- [ ] Persist only validated UI preference and disable conflicting mutations during replay.

## Acceptance criteria

- [ ] 50% Normal submits half-amplitude manual axes; Precision submits one quarter of that amplitude.
- [ ] Recorded commands already contain scaling; playback does not scale again.
- [ ] Slider arrow keys do not move the robot directly.

## Test evidence required

- [ ] Unit: boundary/NaN preference inputs, multiplier math and replay bypass.
- [ ] Browser: pointer/keyboard slider interaction and persisted preference reload.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.

## Boundaries and completion

Preserve authoritative simulation, match, replay and Worker contracts. Views do not manipulate physics directly. New manual interactions must use the approved input/command path. Do not add unsupported battery, weather, lift, account or official-arena claims to match the illustration.
