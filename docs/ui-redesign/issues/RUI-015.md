## Implementation tasks

- [ ] Wrap toggle-style camera methods with idempotent setTop/set3D intent handling.
- [ ] Retarget follow on robot selection and display camera-mode effects clearly.
- [ ] Expose measurement status and cancel without changing simulation state.
- [ ] Add fullscreen capability detection, rejection fallback, exit handling and keyboard labels.

## Acceptance criteria

- [ ] Double-clicking Top View cannot unexpectedly toggle back to 3D.
- [ ] Follow/Top/Reset transitions keep toolbar state synchronized with CameraRig.
- [ ] Measurement works after resize/fullscreen; no pose/tick/config mutation arises from camera actions.
