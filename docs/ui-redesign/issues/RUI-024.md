## Implementation tasks

- [ ] Present Play from start, Stop, elapsed/total simulated time and noninteractive progress.
- [ ] Render completed-verified, stopped and desynchronized results distinctly.
- [ ] Keep live control/mutation admission blocked while replay owns the timeline.
- [ ] Capture completion/verification metadata before operator cleanup or neutralization.

## Acceptance criteria

- [ ] Progress has progressbar semantics, not draggable slider semantics.
- [ ] Compatible ended-match replay starts; incompatible playback leaves results intact.
- [ ] Stop applies agreed neutralization without erasing the recorded verification reason or other lock ownership.

## Test evidence required
