## Summary

The redesigned card must preserve recording ownership and prove a real download, not just receive an in-memory probe result.

## Integration points

- Existing: src/main.ts record/export functions, src/core/CommandBus.ts
- New: src/ui/components/ReplayRecordControls.ts

## Implementation tasks

- [ ] Expose Record Practice and Record Match with reset disclosure and owner-specific labels.
- [ ] Finalize capture on the established safe boundary; reject or explain zero-step export.
- [ ] Keep non-owner controls disabled and guard their handlers.
- [ ] Trigger JSON Blob download and preserve the last valid artifact on errors/cancel.

## Acceptance criteria

- [ ] Visible Stop & Export produces a file whose bytes pass the actual replay parser.
- [ ] No cross-owner button can end the wrong recording or reset its timeline.
- [ ] External command arriving near stop does not produce an out-of-range exported tick.

## Test evidence required

- [ ] Browser: intercept actual download or Blob/anchor dispatch and validate produced bytes.
- [ ] Core integration: immediate stop and stop-between-frames with an external command.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.

## Boundaries and completion
