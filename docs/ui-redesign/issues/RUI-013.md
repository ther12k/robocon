# [RUI-013] Make Stop driving and control handoff safe and reproducible

**Issue ID:** `RUI-013`
**Scope:** `launch`
**Priority:** `P0`
**Milestone:** `M2 - Live practice and match workspace`
**Estimate:** `L` — relative effort, not a calendar commitment
**Labels:** `project:robocon-light-ui`, `type:feature`, `area:controls`, `priority:p0`, `scope:launch`

**Requirements:** `FR-04`, `FR-10`, `FR-19`, `NFR-02`

## Summary

Clearing a visual pressed state is insufficient when queued commands or a detached Worker can still drive the robot.

Planning baseline: `f5092ffa5aa8eeb9aaab016dfa4b8a303c14c12a`. [S09](https://github.com/ther12k/robocon/blob/f5092ffa5aa8eeb9aaab016dfa4b8a303c14c12a/src/core/SimulationCore.ts) [S16](https://github.com/ther12k/robocon/blob/f5092ffa5aa8eeb9aaab016dfa4b8a303c14c12a/src/core/autonomy.ts)

This issue describes proposed work. Re-check the implementation checkout before treating a gap as current; do not reintroduce or duplicate already-landed audit fixes.

## Integration points

- Existing: src/core/CommandBus.ts, src/core/SimulationCore.ts, src/core/autonomy.ts
- New: selected-source cancellation contract in AppController/InputArbiter

## Implementation tasks

- [ ] Define Stop driving as selected-slot neutral input, not a global physics freeze.
- [ ] Cancel undelivered work from an invalidated source and enqueue neutral axes at the documented boundary.
- [ ] Implement Take Manual Control by stopping the selected script, clearing held state and requiring a fresh press.
- [ ] Retain replay/end-match hard-neutralization semantics separately; do not edit recorded delivered commands.

## Acceptance criteria

- [ ] Stopped or replaced sources cannot reassert movement on later ticks.
- [ ] Other robots and already delivered replay history are unaffected.
- [ ] The center pad button is labeled accurately and does not claim hardware emergency-stop certification.

## Test evidence required

- [ ] Unit: pending old-source commands, stale session responses, source swap and selected-slot isolation.
- [ ] Browser: autonomy-to-manual handoff and Stop driving during manual recording replay back correctly.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.

## Boundaries and completion

Preserve authoritative simulation, match, replay and Worker contracts. Views do not manipulate physics directly. New manual interactions must use the approved input/command path. Do not add unsupported battery, weather, lift, account or official-arena claims to match the illustration.
