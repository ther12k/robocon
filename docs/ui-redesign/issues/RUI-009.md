## Summary

Buttons, cards, badges and segmented controls must have consistent visual and semantic states across every scenario.

## Integration points

- New: src/ui/components/primitives.ts, src/ui/styles/components.css

## Implementation tasks

- [ ] Create lightweight DOM factories for buttons, cards, labeled rows, status pills and segment controls.
- [ ] Use text nodes for dynamic labels; support disabled-reason relationships and pending state.
- [ ] Implement focus-visible, hover, pressed and reduced-motion styles.
- [ ] Add icons as local SVG with text alternatives where needed; decorative icons are hidden from assistive technology.

## Acceptance criteria

- [ ] All pointer controls meet the project 44 px target or have an explicitly reviewed dense-control exception.
- [ ] Selected/error/team state is conveyed in text or semantics, not color alone.
- [ ] Dynamic names/logs cannot execute HTML.

## Test evidence required

- [ ] New tests/uiPrimitives.test.ts for accessible names, pressed state and malicious label text.
- [ ] Keyboard/contrast inspection in the component sample page.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.
