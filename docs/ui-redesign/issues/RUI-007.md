## Summary

The current viewport fills the window. A framed center card needs container sizing, stable camera projection and correct pointer coordinates.

## Integration points

- Existing: src/main.ts renderer/onResize, src/sim/CameraRig.ts
- New: src/ui/components/ArenaViewport.ts

## Implementation tasks

- [ ] Mount the existing canvas into the card without replacing its element or WebGL context.
- [ ] Observe content-box size; update renderer/camera on grid, drawer, orientation and fullscreen changes.
- [ ] Handle zero-size/hidden containers and DPR changes safely; retain the cap until profiled.
- [ ] Keep measurement/orbit pointer coordinates relative to the canvas rectangle; add disposal.

## Acceptance criteria

- [ ] One canvas and one renderer survive all layout transitions.
- [ ] A square reference field remains geometrically square at each aspect ratio.
- [ ] Resize/focus changes do not alter simulation tick progression or configuration.

## Test evidence required

- [ ] Browser: resize each breakpoint and toggle an inspector without a window resize event.
- [ ] Check render-buffer dimensions, camera aspect and measurement hit coordinates.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.
