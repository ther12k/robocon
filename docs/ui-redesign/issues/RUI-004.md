## Implementation tasks

- [x] Implement the primitive view models in DATA_CONTRACTS; keep proposed and existing types distinct.
- [x] Project roster, match, replay, camera and autonomy snapshots through narrow read access.
- [x] Tag snapshots with session ID and discard stale generations.
- [x] Publish transition changes promptly and throttle high-rate telemetry to 10 Hz; return unsubscribe functions.

## Acceptance criteria

- [x] Views receive no mutable rigid bodies, scene objects or controller instances.
- [x] Selection/session changes cannot combine one slot name with another slot telemetry.
- [x] Disposed subscribers receive no callbacks; history arrays remain bounded.
