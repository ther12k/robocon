## Integration points

## Implementation tasks

- [ ] Enable ?ui=light opt-in and keep ?ui=legacy as a bootstrap-only fallback.
- [ ] Run smoke/fixture parity in both shell modes; mount exactly one.
- [ ] Collect pilot usability evidence and record unresolved issues with owners.
- [ ] After approval switch the default to light; retain a documented short stabilization rollback window.

## Acceptance criteria

- [ ] Rollback changes only shell choice, not data formats or source configuration.
- [ ] A shared replay link behaves consistently in both modes under compatible build conditions.
- [ ] The default switch is made only with evidence and explicit maintainer approval.

## Test evidence required

- [ ] Production preview smoke for flag/default/rollback paths.
- [ ] Pilot: five proposed evaluators perform practice and record/reload tasks; record actual sample size.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.
