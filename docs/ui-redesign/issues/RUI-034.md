## Implementation tasks

- [ ] Compare normalized delivered command streams and final states for equivalent manual/record/replay journeys.
- [ ] Test every rejected state transition from STATE_AND_CAPABILITIES at controlled fixed-step boundaries.

## Acceptance criteria

- [ ] No old audit test is removed merely because it fails after the refactor.
- [ ] Illegal actions preserve score/winner/ownership/capture artifact; allowed selected reset has only its specified effects.
- [ ] New UI accepts only the same replay format and validates final results before cleanup.

## Test evidence required

- [ ] Full unit/integration suite plus paired legacy/light fixture runs on identical runtime/config.
- [ ] Record exceptions requiring domain changes as explicit review decisions, not golden-file churn.
- [ ] Attach actual source SHA, command/output or review artifact, and any blocked checks. Do not claim execution from source inspection.

## Boundaries and completion

Preserve authoritative simulation, match, replay and Worker contracts. Views do not manipulate physics directly. New manual interactions must use the approved input/command path. Do not add unsupported battery, weather, lift, account or official-arena claims to match the illustration.
